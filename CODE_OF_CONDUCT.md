# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, argue with evidence rather than with people, and assume good faith. Telling
someone their result is wrong is welcome here, provided you show why. Harassment, personal attacks
and discriminatory language are not.

## Reporting

To report a conduct issue privately, contact the maintainer, Keng Lee, through the contact details on
their GitHub profile. Reports are kept confidential. The maintainer may remove, edit or reject
comments, commits, issues and other contributions that break this code of conduct, and may block
contributors who do so repeatedly.
