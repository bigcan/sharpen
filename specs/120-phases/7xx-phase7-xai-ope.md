# Phase 7: Explainability (XAI) & Off-Policy Evaluation (OPE)

## Motivation
RL agents are often "black boxes." To deploy them in finance, we need to understand *why* they make specific decisions (Trust) and estimate their performance without risking capital (Safety).

## Requirements

### 1. Explainability (XAI)
- **SHAP (SHapley Additive exPlanations):** Use `shap.DeepExplainer` (or KernelExplainer) to quantify feature importance for PPO agents.
- **Temporal Stability:** Analyze how feature importance changes over time (e.g., Bull vs. Bear).
- **Integrated Gradients:** (Already partially implemented) Ensure it works with the PPO Actor network.

### 2. Off-Policy Evaluation (OPE)
- **Importance Sampling (IS):** Estimate the value of a target policy $\pi$ using data generated by a behavior policy $\beta$.
- **Weighted Importance Sampling (WIS):** Reduce variance of IS.
- **Doubly Robust (DR):** Combine IS with a Q-function model for lower variance.

## Deliverables
1.  `finrl_pro_ds/explainability/ppo_explainer.py`: Wrapper to apply SHAP/IG to PPO agents.
2.  `finrl_pro_ds/ope/estimators.py`: Implementation of IS, WIS, and DR estimators.
3.  `scripts/run_phase7_xai.py`: Script to generate SHAP plots for Phase 6 specialists.

## Success Criteria
- Generate a SHAP summary plot showing the top 10 features for the "Bull" specialist.
- Compute OPE estimates (WIS) for the "Bear" specialist on out-of-sample data.
