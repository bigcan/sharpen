# FinRL Pro Scaffold

FinRL Pro extends the open-source FinRL Podracer project with institutional
workflow guardrails: reproducibility fingerprints, risk controls, structured
observability, and compliance-ready reporting. All new functionality lives
inside the `finrl_pro/` namespace so upstream code remains untouched.

## Project Layout

- `finrl_pro/` – Python package containing training, evaluation, explainability,
  MLOps, and utility modules specific to FinRL Pro.
- `specs/` – Source of truth for feature plans, task breakdowns, and API
  contracts generated by Spec-Kit.
- `docs/` – Knowledge base for runbooks and extension workflows.
- `tests/` – Pytest suite covering integration guards, reproducibility, risk,
  and reporting.
- `docker/` – Container definitions for the FinRL Pro developer environment.
- `conf/` – Environment overlays and `.env` samples for MLflow + DVC setup.

## Environment Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]

# Optional formatters/linters if not installed globally
pip install ruff black mypy
```

Configure MLflow and DVC endpoints before running pipelines:

```bash
cp conf/finrl_pro.env.example conf/finrl_pro.env
dvc remote add -d finrlpro-s3 s3://finrl-pro-artifacts
dvc remote modify finrlpro-s3 endpointurl <S3_ENDPOINT>
export $(grep -v '^#' conf/finrl_pro.env | xargs -0)
```

## Core Workflows

- **Scaffold a module** inside the safe extension boundary:
  ```bash
  python -m finrl_pro scaffold finrl_pro.agents.new_agent \
    --doc "Custom FinRL Pro agent implementation"
  ```
- **Run a training job** that records reproducibility fingerprints:
  ```python
  from pathlib import Path
  from finrl_pro.configs.fingerprint_store import FingerprintStore
  from finrl_pro.training.trainer import Trainer

  store = FingerprintStore(manifest_path=Path("finrl_pro/configs/fingerprints.yaml"))
  trainer = Trainer(fingerprint_store=store)
  trainer.run(
      config_path="finrl_pro/configs/experiment_sp500.yaml",
      dataset_hash="dvc://datasets/sp500",
      seed=42,
      module_versions={"finrl_pro.training.trainer": "main"},
      metrics={"sharpe_ratio": 1.1, "max_drawdown": 0.12, "volatility": 0.25},
      artifact_uris=["s3://finrl-pro/checkpoints/sp500.pt"],
      baseline_reference="benchmarks:sp500_rolling_1y",
  )
  ```
- **Replay an experiment** using the stored fingerprint manifest:
  ```bash
  python -m finrl_pro.training.commands.reproduce <fingerprint_id> \
    --manifest finrl_pro/configs/fingerprints.yaml
  ```
- **Evaluate and generate compliance reports** against the benchmark catalog:
  ```python
  from pathlib import Path
  from finrl_pro.eval.base import EvaluationContext
  from finrl_pro.eval.benchmark_catalog import BenchmarkCatalog
  from finrl_pro.eval.report_pipeline import ReportPipeline
  from finrl_pro.eval.walk_forward import WalkForwardEvaluator

  catalog = BenchmarkCatalog(manifest_path=Path("finrl_pro/configs/benchmarks.yaml"))
  catalog.load()

  evaluator = WalkForwardEvaluator(catalog=catalog)
  context = EvaluationContext(
      fingerprint_id="<fingerprint_id>",
      benchmark_id="sp500_rolling_1y",
      walk_forward_splits=3,
  )
  evaluation = evaluator.evaluate(context)

  pipeline = ReportPipeline()
  report = pipeline.generate(fingerprint_id=context.fingerprint_id, evaluation=evaluation)
  print(report.summary_location)
  ```

Each pipeline emits fingerprints to
`finrl_pro/configs/fingerprints.yaml`, logs MLflow telemetry, and writes reports
under `reports/<fingerprint_id>/` with SHAP diagnostics and variance analysis.

## Risk & Observability Guardrails

- Define capital exposure thresholds in `finrl_pro/configs/risk_profiles.yaml`
  and load them through `RiskControlPolicy` before training.
- Structured logs flow through `finrl_pro.mlops.logger.MLOpsLogger`, emitting
  JSON payloads suitable for centralized observability tooling.
- Risk alerts are routed by `finrl_pro.mlops.alerting.RiskAlertDispatcher` and
  raised automatically when drawdown, leverage, or sandbox policies are
  violated.
