## Executive Summary

**The single dominant cross-cutting fault: deploy-gating evidence across the entire active fleet was produced under observation/cost regimes that the live system does not reproduce — and the corrective machinery built for sg1-btc was never propagated to the other strategies.** The same bug *class* that erased the sg1-btc edge (the X2 coarse-bar look-ahead, worth ~0.67 PF and proven to be the *entire* edge) is still live in three independent surfaces: (1) it is **unfixed in `MultiScaleCryptoHandler`** (CMGP1, P2-01, **S1**), a landmine that will contaminate the next CMGP1 verdict; (2) every live drift/retrain **baseline was recorded under the pre-X2 leaky observation builder** (P10-01, **S1**), so the action-drift trackers gating live capital compare X2-fixed live actions against a future-peeking baseline; and (3) the V7 step loop itself **earns the same-bar (t-1→t) return on a position decided at t with bar-t's close in the observation** (P3-01, **S1**) — the base-scale analogue of X2 that the X2 fix explicitly never closed. Layered on top, **GMGP1 was never cost-corrected the way SG-1 was** (P3-02, **S1**): every GMGP1 graduation config leaves `slippage_base_bps` unset (env default 0.0) while the live engine crosses the spread ~5 bps/trade — the exact frictionless-artifact trap that sank SG-1-BTC.

**Top S1/S2 themes:**

1. **The X2 leak is not contained — it is mirrored, un-baselined, and un-closed at base scale.** P2-01 (crypto handler, S1), P10-01 (stale leaky baselines fleet-wide, S1), P3-01 (V7 same-bar base-scale look-ahead, S1) are three distinct, currently-live instances of the same look-ahead family. None is caught by a test (P2-02, P3-05, P5-01 test blind spots).

2. **The single-cost-regime fault repeats per stage.** Selection (HPO/L1/2.5), Stage-3 WF, and Stage-4 OOS all run cheaper-than-live for GMGP1: GMGP1 OOS configs are frictionless (P8-02, S2), the gmgp1-btc retrain gate measures PF at *training* friction not live (P10-02, S2-but-cost-correct after S1 re-base), and the cost-drift retrain trigger is disabled for gmgp1-btc precisely where it should fire (P10-03, S2).

3. **Documented safeguards have no Python consumer — false assurance at six stages.** Training-health kill gates (P5-01, S2), the [15,40] multiplicity check skipped for all non-crypto (P5-02, S2), the ≥22-month window REJECT (P5-03), challenge_target_hit_rate at L1/2.5 (P6-03, S2, with a *dead* validator guard from a `v2.2`/`v2.3` protocol-string mismatch), PF-XCHECK at L1 and WF (P6-08/P7-04, S2/S3), and the FTMO compliance wrapper (P8-06, S2, dead + wrong dollar/return denominator).

4. **The decision/validation layer is non-reproducible and over-states robustness.** The L1 gate verdict is an untracked, no-provenance JSON with no committed evaluator (P6-01, S2); the WF bootstrap PROMOTE that overrode a G3 FAIL was a *manual* override against a *weaker fixed* solo comparand with no version-controlled generator (P9-02, S2); the published OOS verdicts are **stale relative to their own sanity-guard code** (P8-03, S2); the drift baseline bake script hardcodes `decision="PROMOTE"` while the WF verdict it reads says FAIL (P9-06, S2); `chosen_rule` is declared in three places with no cross-check (P9-01); and `G_STRESS` INCOMPLETE never flips a passing WF to FAIL (P7-02, S2).

5. **Highest-value missing overfitting control:** no Deflated-Sharpe / selection-multiplicity deflation anywhere (P11-01, S2) — the repo has PSR but only ever calls it at SR0=0, so it answers "is SR>0", never "does SR survive the search".

**Credit where due (S4 positives):** The low-level correctness machinery is genuinely strong and should be preserved — V7 coarse-bar causal map + negative tripwire test (P1-08, P2-03), LEAK-1 EMA-Z per-split isolation byte-verified (P1-09, P2-04, P9-07), sim↔live mid-interval parity for the V7 single-asset path (P2-05, P10-09), debt-free SHORT-ACCT (P3-09), DSR faithful to Moody-Saffell with a passing numeric tripwire (P4-01/P4-02), B5 leverage-invariant deadband (P4-08), single-source fee accounting (P4-07), BUG-01/BUG-03 enforced + NopPruner correct (P5-09/P5-10/P5-11), the strict gates-YAML-driven Stage-3 WF evaluator (P6-06), the faithful fixed-lot stress sub-report (P7-07), sg1-btc as a correct Stage-4 OOS template (P8-09), fail-closed bundle SHA chain + well-engineered live safety layers (P10-10/P10-11), and above-median academic practice on costs/normalization/Politis-Romano bootstrap (P11-06).

**Verdict:** Live capital is protected from blow-up (drift WARN/CRIT, daily-loss median+2-bar backstop, intrabar-DD, persistent halt, fail-closed bundles are all sound). But **no deploy-gating verdict on this fleet is currently trustworthy** — the sg1-btc de-leak proved the read can invert entirely. Before un-halting ANY multiscale strategy, the three S1 leak instances must be closed and every drift/retrain baseline regenerated on X2-fixed, cost-corrected code.
